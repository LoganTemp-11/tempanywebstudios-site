# A robots.txt only carries weight at the root of a domain
# (https://example.co.uk/robots.txt). This copy sits in a subfolder, so no
# crawler will read it here. It ships anyway so a client can see precisely what
# lands on their own domain, where it does sit at the root.

# Tempany Web Studios note: do NOT add a Disallow for this folder to the root
# robots.txt. The demo is kept out of the index by the noindex meta tag on every
# page, and a Disallow would stop crawlers reading that tag at all, which leaves
# the URL indexable from inbound links with no description under it.
